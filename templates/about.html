01

Dataset & labeling

The workflow loads a stress dataset (CSV) with an integer label column condition, then predicts: Medium level stress (0), Low stress (1), High stress (2).

02

Feature engineering

ID-like columns are removed (e.g., uuid* and datasetId), and the remaining HRV features are used as the ANN input vector.

03

Model pipeline

StandardScaler → Keras ANN → argmax class → label mapping.

HRV signals used (examples)

Your dataset includes a wide HRV feature set spanning time-domain, frequency-domain, and nonlinear measures. These are commonly used to quantify autonomic nervous system changes under mental load and pressure.
